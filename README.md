Python Lab 3 – Star Patterns

Description

This repository contains Python programs based on star patterns using loops and conditional statements.

Programs Included

1. Butterfly Star Pattern

- File Name: "Butterfly_Star_Pattern.py"
- Prints a butterfly-shaped star pattern.
- Uses nested for loops to print the upper and lower halves of the pattern.

2. Hollow Diamond Pattern

- File Name: "Hallow pattern.py"
- Prints a hollow diamond-shaped star pattern.
- Uses nested for loops and conditional statements to print stars at the boundaries.

Concepts Used

- Python For Loops
- Nested Loops
- If-Else Statements
- User Input
- Pattern Printing

How to Run

1. Open the Python file in VS Code.
2. Open the terminal.
3. Run the following command:

python Butterfly_Star_Pattern.py

For Hollow Diamond:

python "Hallow pattern.py"

4. Enter the number of rows when prompted.
